# Ice-Scream-Life-Virtual-Joystick-GDScript-
Виртуальный джойстик для мобильной хоррор-игры Ice Scream: Life — фанатский проект от BecauseDev IT Studio. Сделан на Godot 4.7 выдаёт direction (Vector2) для движения игрока. Чистый GDScript, без зависимостей. Лицензия MIT — используй свободно, будем рады упоминанию. Фанатский проект, не связан с Keplerians.
